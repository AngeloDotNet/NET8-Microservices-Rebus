# Microservices with Rebus

This is a sample project demonstrating how to use Rebus to build microservices. It consists of two services: `OrderService` and `InventoryService`. The `OrderService` sends messages to the `InventoryService` to check if the items in an order are in stock.

## 🛠️ Installation

### Prerequisites

- .NET 8.0 SDK (latest version)
- RabbitMQ
- SQL Server
